# AlphaWell Frontend
AI-Powered Energy & Production Intelligence Platform

AlphaWell is a modern frontend application built using **React + Vite**, designed to support AI-driven energy analytics, production forecasting, and operational intelligence workflows.

This repository contains the frontend UI for AlphaWell Intelligence.

---

## Tech Stack

- React 18
- Vite
- JavaScript (ES6+)
- ESLint
- REST-based API integration

---

## Getting Started

### Prerequisites

- Node.js >= 18
- npm or yarn

---

### Installation

```bash
git clone <repository-url>
cd alphawell-frontend
npm install
